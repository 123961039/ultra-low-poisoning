## 🛠️ Requirements

- **Python** 3.10 or later
- **GPU** with at least **24 GB VRAM** (e.g., NVIDIA A10, A100, RTX 3090)
- **CUDA** 11.8+ (tested with 12.8)
- **OS** Linux (recommended) – the scripts are written for Linux, but can be adapted to Windows

Install the dependencies:

pip install -r requirements.txt
